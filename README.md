# Перенумерация листов для pyRevit

Кнопка для безопасной пакетной перенумерации листов Revit с предпросмотром,
ручным порядком и настраиваемой автосортировкой.

## Возможности

- выбор листов для перенумерации;
- префикс, суффикс, стартовый номер, шаг и количество разрядов;
- до пяти пользовательских групп автосортировки по названию листа;
- ручное перемещение одной или нескольких строк мышью;
- автоматическая прокрутка при перетаскивании;
- проверка занятых номеров и конфликтов;
- одна транзакция Revit с откатом при ошибке;
- одна операция Undo для всей перенумерации.

## Совместимость

- проверено в Autodesk Revit 2026;
- рекомендуется актуальная версия pyRevit 5.2+ или 6.x;
- рекомендуемый движок — стандартный IronPython 2.7;
- MCP-сервер для работы кнопки не требуется.

Код учитывает различия `ElementId` между версиями Revit, но версии Revit,
отличные от 2026, следует сначала проверить на копии проекта.

## Установка из GitHub Release

1. Скачайте архив `SheetRenumber-...zip` из раздела Releases.
2. Закройте Revit.
3. Распакуйте папку `SheetRenumber.extension` в:

   ```text
   %APPDATA%\pyRevit\Extensions\
   ```

4. Проверьте итоговый путь:

   ```text
   %APPDATA%\pyRevit\Extensions\SheetRenumber.extension\pyRevit.tab\Sheets.panel\Renumber Sheets.pushbutton\script.py
   ```

5. Запустите Revit. Если он уже открыт, выполните `pyRevit → Reload`.

Не устанавливайте одновременно две копии кнопки из разных расширений.

## Установка через Git

Для приватного репозитория сначала выполните вход в GitHub CLI, затем:

```powershell
git clone https://github.com/ZeroNurik/pyrevit-sheet-renumber.git `
  "$env:APPDATA\pyRevit\Extensions\SheetRenumber.extension"
```

## Версии и откат

Каждая стабильная версия отмечается Git-меткой (`v1.0`, `v1.1` и далее).
GitHub Release с тем же номером содержит готовый установочный ZIP.

Для отката проще всего скачать ZIP нужной версии из Releases и заменить им
папку `SheetRenumber.extension` при закрытом Revit.
